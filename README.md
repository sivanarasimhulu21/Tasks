## Import Existing EC2 Instances into Terraform (Seamless Migration Guide)

Already running EC2 instances but want to bring them under Terraform management? This guide shows you how to safely import your existing infrastructure into Terraform state without downtime. Learn how to map live AWS resources to your configuration, use `terraform import` effectively, and ensure your setup is fully aligned with real-world infrastructure. Perfect for transitioning from manual setups to Infrastructure as Code (IaC) with confidence.
